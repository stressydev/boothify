# 📸 Boothify - Free Online Photo Booth

![Boothify](https://img.shields.io/badge/Status-Live-brightgreen) ![Next.js](https://img.shields.io/badge/Next.js-16.0.10-black) ![License](https://img.shields.io/badge/License-MIT-blue)

**Create stunning photo booth strips for free — no sign-up required!**

Boothify is a modern, browser-based photo booth application that lets you capture classic 4-photo strips with custom borders, text, and instant downloads. Perfect for parties, weddings, events, or just having fun with friends!

🌐 **Live Demo:** [boothify.app](https://boothify.app)

---

## ✨ Features

- 📸 **Classic 4-Photo Strips** - Timeless photo booth format
- 🎨 **Custom Designs** - 9 built-in border styles + custom border upload
- ✍️ **Personalized Text** - Add custom text with 10 font styles
- ⚡ **Instant Download** - High-resolution output (3x scale)
- 🎯 **Smart Countdown** - 3, 5, or 10-second timer options
- 🔄 **Mirror Mode** - Flip camera view for perfect selfies
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- 🚀 **No Sign-Up** - Start creating immediately
- 💯 **100% Free** - No hidden costs or subscriptions
- 🔒 **Privacy First** - All processing done in your browser

## 🚀 Quick Start

### Prerequisites

- Node.js 18+ 
- pnpm (recommended) or npm

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/boothify.git

# Navigate to project directory
cd boothify

# Install dependencies
pnpm install

# Run development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
